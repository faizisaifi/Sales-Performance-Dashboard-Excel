![Sales Performance Dashboard](Screenshot%202026-09-25%20101841.png)
## Project Overview

An interactive Sales Performance Dashboard built in Microsoft Excel to analyze sales performance across different business dimensions.

## Dashboard Features

- Sales analysis by sub-category
- Profit gained over time
- State-level sales visualization
- Customer count by year
- Top 5 customers by profit
- Monthly sales analysis
- Interactive Category and Year slicers
